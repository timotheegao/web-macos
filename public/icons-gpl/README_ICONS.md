# Icons (GPL-3.0)

The SVG files in this directory are taken **unmodified** (except `calendar.svg`, where the date text paths were removed so the app can overlay today's date) from:

- **MacTahoe icon theme** by Vince Liuice — https://github.com/vinceliuice/MacTahoe-icon-theme
- **WhiteSur icon theme** by Vince Liuice — https://github.com/vinceliuice/WhiteSur-icon-theme

Both are licensed under **GNU GPL v3** (see `COPYING`; upstream author files: `AUTHORS-MacTahoe`, `AUTHORS-WhiteSur`).
